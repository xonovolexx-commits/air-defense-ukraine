# Повітряна Оборона - Україна

Гра в стилі arcade про захист України від російських повітряних атак.

## Запуск

1. Відкрийте `index.html` у браузері.
2. Або завантажте в GitHub Pages.

## Мета

- збивати російські винищувачі та ракети;
- захищати українську карту;
- не допустити влучання до цілей.

## Управління

- клікайте по ворожим цілям на карті;
- натискайте `SPACE`, щоб стріляти;
- `R` — перезапуск після поразки.
